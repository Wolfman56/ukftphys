# Fermi Mirror Validation: `analysis`

Physics Analysis scripts and notebooks.

## Key Analyses
1.  **Entropic Discriminator Calibration ($D_E$)**:
    *   **Goal**: Apply the UKFT "Entropic Discriminator" method to real QCD jets to confirm their fractal properties (low $D_E$).
    *   **Data**: CMS Open Data (Run 2) - Standard Model Jets.

2.  **Mirror Fermion Mass Search**:
    *   **Goal**: Search for anomalies in the 320 GeV di-jet/tri-jet mass distribution.
    *   **Method**: Bump hunting in the "high-$D_E$" tail of the distribution.

3.  **Background Modeling**:
    *   **Goal**: Validate the $t\bar{t}$ and $W+jets$ background models used in simulations (Exp 40) against real data.
